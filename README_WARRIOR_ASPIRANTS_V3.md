# Warrior Aspirants V3 — Complete Master Build

Warrior Aspirants is a free-first Android exam-preparation app for SSC CGL, Railway and UP SI.

## V3 additions
- Expanded master syllabus/topic map across 14 subject areas.
- SSC CGL: Quant, Reasoning, English, GA/Static GK, Computer.
- Railway: Quant, Reasoning, GA/Science, Computer, Current Affairs and General Hindi coverage.
- UP SI: General Hindi, Law & Constitution, Numerical/Mental Ability, Intelligence/Reasoning, GK/UP GK and Current Affairs coverage.
- Topic records include theory, concept, rules/formula, tricks, examples, visual revision guidance, PYQ focus, solution method, revision, common mistakes and mastery checklist.
- Existing V2 clean UI and study features retained.
- PYQ hub continues to use verified source links rather than redistributing third-party copyrighted paper text.
- Current Affairs is a structured category; live facts must be refreshed from configured feeds/official sources.

Build with GitHub Actions workflow `.github/workflows/build-apk.yml`.
