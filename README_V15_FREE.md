# Warrior Aspirants V15 — FREE COMPLETE PREPARATION ENGINE

V15 adds a fully local/free-first practice and mock layer on top of the V14 curriculum.

## Added
- Question Bank with subject filter and search
- Instant answer checking
- Automatic mistake-book capture for wrong practice answers
- Timed mock tests
- SSC CGL Mixed mock mode + subject-wise mock modes
- +2 correct / -0.50 wrong / 0 unattempted scoring
- Mock result, attempt count and best-score persistence
- Practice attempt analytics
- Topic completion and subject-wise progress analytics
- Weak-area/next-target progress summary
- Existing offline curriculum, revision, notes, daily tasks, FIGHTER fallback, PDF library and optional Google/online sync retained

## Free-first
The core question practice, mock scoring, progress, notes, revision and bundled curriculum work without paid APIs or subscriptions. Online AI/current-affairs/cloud features remain optional.

## Important
The bundled V14 curriculum currently contains 261 topics and 66 questions. V15 provides the engine to consume and test that content; a later content pass can expand the question corpus with verified PYQs and larger chapter-wise practice sets.

## Build
This project targets Android with the existing Gradle configuration. If the environment cannot reach Gradle distribution servers, an APK may not be buildable there; this does not mean the source is invalid.

## V15.1 — PYQ Source Library
Warrior Aspirants now includes a PYQ Library for SSC CGL 2023–2025 with year-wise source pages and a solutions source. The APK remains free-first and does not bundle large third-party paper text; it opens the source pages so the learner can access complete papers and answer keys online.
