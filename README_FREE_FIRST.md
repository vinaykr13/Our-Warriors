# Warrior Aspirants V13 — Free-First Edition

Warrior Aspirants is designed so core exam preparation works without paid courses or mandatory paid APIs.

## Included offline
- Bundled exam/topic curriculum
- Theory, concepts, formulas/rules, tricks, examples, diagrams
- PYQs, solutions, practice, revision, mistake book, tests, progress
- Local study timer and notes
- Core content remains usable without internet

## Optional online features
- Google account connection
- YouTube channel/videos/analytics
- Google Drive
- Remote content updates
- Current affairs feeds
- FIGHTER AI API (only if an external API key is configured)

## Cost control
- OPENAI_API_KEY is optional. Without it, FIGHTER returns an offline fallback instead of failing.
- Google/YouTube/Drive are optional and use official APIs; quotas/Google policies apply.
- No paid course or live-class dependency is included.
- Do not put Google client secrets or API keys inside the APK.

- Core content remains bundled in app assets for offline use.
- Online services remain optional.
