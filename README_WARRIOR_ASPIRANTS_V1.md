# Warrior Aspirants V1 — FREE-FIRST

A new standalone Android exam-preparation app based on the prepared V16 feature set.

## Included
- 261-topic offline study curriculum
- Theory, concept, formula/rules, tricks, examples, revision and mistake guidance
- Question Bank and timed Mock Test engine
- Negative marking and progress tracking
- PYQ Hub with 2023–2025 verified source/solution links
- Current Affairs update architecture
- Notes, Daily Tasks and Revision
- FIGHTER offline mode; optional online AI server
- PDF Library
- Optional Google/YouTube/Drive integrations
- GitHub Actions debug APK build
- Free-first: no compulsory paid subscription or paid API

## GitHub build
Upload the project files to the root of a new repository, then run:
Actions → Build Warrior Aspirants APK → Run workflow.
The APK is published as the `Warrior-Aspirants-debug-apk` artifact.
